# アプリの挙動のレビュー

## 受け付ける形式

| 形式 | ペルソナの体験手段 |
| --- | --- |
| Web アプリの URL（本番、ステージング、ローカル） | 同梱の Playwright MCP で操作 |
| ローカルで起動するアプリ（起動コマンド付き） | オーケストレータが起動し、URL を渡す |
| CLI ツール | Bash で実行（専門家と関心層のみ。無垢・受信者には CLI は原則向かない） |
| ネイティブアプリ（iOS / Android / デスクトップ） | 作者が用意した画面録画の切り出し画像、またはスクリーンショット連番を順に閲覧。操作はできないため、ペルソナには「操作はできない。画面の流れを見ている」と明示する |

ネイティブアプリの実機操作用 MCP は同梱していません。環境にシミュレータ操作の MCP があれば、アクセス手順を「操作できる」形に書き換えて使ってかまいません。

## 準備手順

1. 起動手順を確認し、URL に到達できることを確かめる（`curl -sI <URL>`）。ローカル起動が必要なら起動し、終了方法も控える。
2. テスト用アカウントが必要なら、作者から受け取り、アクセス手順に含める。ペルソナが自分でアカウントを作る体験が重要な場合は、作らせる。
3. データの状態を初期化できるなら初期化する（ペルソナは「初めて使う人」である）。
4. 録画・スクリーンショットの場合は `work/app/` に順番付きで並べる。
5. **タスクの与え方に注意する。** 「〜を登録してみてください」のような具体的タスクは作者の意図を含みやすい。開始地点だけを指定し、専門家には「代表的な使い方を自分で見つけて試す」、受信者には「あなたの状況でやりたくなったことをする」とする。アプリ自体が初回起動で目的を説明しているなら、それに従わせる。

## ペルソナに渡すアクセス手順（雛形）

Web アプリ：

```
1. ブラウザで次の URL を開いてください：<URL>
2. 初めて使う人として、自由に触ってください。<アカウント情報が必要なら：ログインには次を使ってください：…>
3. 課金、外部への投稿、他人に影響する操作はしないでください。
4. 使える時間の目安を過ぎたら、途中でもやめて回答に移ってください。
```

録画・スクリーンショット：

```
1. 次の画像を順に見てください：<絶対パスの一覧>
2. これはアプリを操作している画面の流れです。自分で操作することはできません。
3. 各画面で「自分なら次に何をするか」「次の画面は予想どおりだったか」を記録してください。
```

## 専門家の既定プロファイル

| 既定 | 代替 |
| --- | --- |
| モバイル・Web アプリの QA エンジニア（探索的テストの経験が豊富） | プロダクトデザイナー、アクセシビリティ専門家、該当ドメインの業務専門家 |

### 専門家への具体的な問い

1. 初回起動から「このアプリの価値がわかった」と感じるまでに、何ステップ・何分かかったか。
2. 途中で迷った画面、戻れなかった操作、取り消せなかった操作はどれか。
3. エラー時、空の状態、通信待ちのときの表示は適切か。
4. 権限（通知、位置情報、ヘルスデータ等）の要求は、理由が説明されていたか。
5. 動作の遅さ、ちらつき、レイアウト崩れはあったか。どの画面か。
6. 画面上の用語で、利用者に通じなさそうなものはどれか。
7. 再現性のある不具合はあったか。手順を書く。

## 関心層・無垢・受信者の知識状態のヒント

- 関心層：同種のアプリをいくつか使ったことがある。アプリの機能名や業界用語は「知らないこと」に。
- 無垢：アプリの画面に出てくる機能名・略語・設定項目名を列挙して「知らないこと」に入れる。スマホの基本操作は知っている。
- 受信者：使う場面（どこで、どの端末で、どれくらいの時間、何がきっかけで）を具体的に書く。

## 判定の観点（シンセサイザーに渡す）

- 想定受信者は、作者が価値だと考えている体験（非公開情報の想定アウトカム）に自力で到達したか。到達しなかった場合、どの画面で止まったか
- 各ペルソナが「次にやりたくなった操作」は、アプリが用意している導線と一致したか
- 専門家が挙げた不具合のうち、受信者の体験ログにも現れているものはどれか（独立に再現した問題は重い）
- 権限要求や登録を求められた時点で、受信者は続けたか、やめたか

## 必要なツール

- 同梱の Playwright MCP（Web アプリの操作、`--isolated` でログイン状態を持ち込まない）
- Bash（ローカル起動、CLI）
- Read（録画・スクリーンショットの閲覧）
