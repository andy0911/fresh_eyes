# ペルソナの人物像と知識状態の書き方

ペルソナは属性（性別・年齢・人種）ではなく、**持っている文脈と知識の量**で切ります。属性ベースのペルソナはステレオタイプを再生産し、模擬の精度も上がりません。特に「全く無垢な人」は、プロンプトで「知らないふりをして」と頼むだけでは専門知識に戻ってしまうことが実証されているため、「何を知っていて、何を知らず、どう誤解しやすいか」を列挙した仕様で定義します。

## 共通フォーマット

```
### <ペルソナ名>
#### 人物像
立場、普段していること、この成果物に出会ったきっかけ（中立に）
#### 知っていること
#### 知らないこと
#### 誤解しやすいこと
#### 状況
端末、時間の余裕、気分、何かを探している途中か
```

## ペルソナ別の書き方

### 専門家

- 職能は種別スキルの既定か `--expert`。成果物の題材に合わせて具体化する（「編集者」ではなく「商業メディアで健康分野を10年担当した編集者」）。
- 「知っていること」に、その職能が普段使う規範・チェック観点を2〜4個書く。
- 「知らないこと」には、作者の意図・背景・制作経緯を明示的に入れる。
- 種別スキルの「具体的な問い」を付ける。抽象的な「批評してください」より、「誤りを特定してください」の方が精度が高い。

### 関心がある人

- 分野への興味の持ち方（趣味、最近気になっている、入門書を1冊読んだ程度）を書く。
- 「知っていること」は一般向けの知識まで。「知らないこと」に、その分野の専門用語の例を3〜6個挙げる。例は**成果物の表層（見出し・画面の語彙）から拾う**。
- 「誤解しやすいこと」に、一般の人が持ちがちな思い込みを1〜2個。

### 全く無垢な人

- 一般常識と日常の読み書きはできる。成果物の題材分野については、語彙も概念も知らない。
- 「知らないこと」には、成果物の表層に現れる専門語・固有名詞・略語を**できるだけ網羅して**列挙する。この列挙が演技の崩れを防ぐ。
- 「誤解しやすいこと」に、字面から別の意味に取りそうな語があれば書く。
- `--goal` に由来する語を列挙に入れてはいけない。表層に現れていない概念まで「知らない」と書くと、逆に目的を示唆する。

### 想定受信者

- `--audience` から書く。立場・状況・動機・知識状態を具体化する。
- 「この成果物に出会ったきっかけ」は中立にする（「知人からリンクが送られてきた」「検索結果に出てきた」「会議で配布された」）。
- 期待する行動（登録する、購入する、承認する）は**絶対に書かない**。受信者が自然にその行動を取るかどうかが、まさに測りたいことである。
- 状況（端末、時間、気分）は、作者が想定する実際の受信場面に合わせる。

## 例（記事：個人開発の運動習慣アプリの紹介記事の場合）

```
### 全く無垢な人
#### 人物像
日常的にスマホで SNS やニュースを見る会社員。健康や運動には特別な関心がなく、アプリ開発にも詳しくない。SNS のタイムラインに流れてきた記事を何気なく開いた。
#### 知っていること
スマホの基本操作、アプリをストアから入れること、一般的なニュース記事の読み方
#### 知らないこと
「習慣化」「ヘルスケア連携」「Apple Watch のワークアウト」「サブスクリプション」「個人開発」「β版」「TestFlight」
#### 誤解しやすいこと
「ワークアウト」を本格的な筋トレのことだと思う
#### 状況
スマホ、昼休みの5分、特に何も探していない
```
